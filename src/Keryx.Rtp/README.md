# Keryx.Rtp

RTP packet model, RTCP (SR/RR/SDES/BYE) and first-class typed RTCP feedback (PLI, FIR, NACK, transport-cc), plus media packetizers for H.264 (STAP-A/FU-A) and Opus behind a generic packetizer interface.

Part of [Keryx](https://github.com/Proxeno/keryx), a from-scratch WebRTC stack for .NET licensed under Apache-2.0.
