# Keryx.Dtls

DTLS 1.2 handshake state machine and record layer for WebRTC (client and server roles, use_srtp / RFC 5764), built on System.Security.Cryptography primitives only. NOT yet independently security reviewed - see the repository README before production use.

Part of [Keryx](https://github.com/Proxeno/keryx), a from-scratch WebRTC stack for .NET licensed under Apache-2.0.
