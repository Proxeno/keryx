# Keryx.Sdp

SDP parsing and generation covering the JSEP offer/answer subset WebRTC needs: BUNDLE, rtcp-mux, ICE and DTLS attributes, rtpmap/fmtp/rtcp-fb, and trickle ICE candidates.

Part of [Keryx](https://github.com/Proxeno/keryx), a from-scratch WebRTC stack for .NET licensed under Apache-2.0.
