# Keryx

The Keryx WebRTC stack for .NET: an RTCPeerConnection-style API composing the Keryx STUN, ICE, SDP, DTLS, SRTP, RTP and SCTP layers. Reference this single package to get the whole stack.

Part of [Keryx](https://github.com/Proxeno/keryx), a from-scratch WebRTC stack for .NET licensed under Apache-2.0.
